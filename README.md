# Doppel GTM Context OS

This repo is the go-to-market context system for [Doppel](https://www.doppel.com). It holds the company context (ICP, positioning, messaging, brand), research, playbooks, learnings, meeting notes, and campaign output that Claude and the team use to produce GTM work.

Start with `CLAUDE.md` for how the folders work and the rules every piece of work follows. Each week's goals live in `weekly-priorities/`, and the matching `work-log/` file records what changed.
